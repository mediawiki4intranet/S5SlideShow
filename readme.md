# S5SlideShow
**S5SlideShow** — это расширение для MediaWiki 🎞️
- «на лету» превращает вики-статьи в полноэкранные интерактивные HTML-презентации ⚡
- базируется на [S5 (Simple Standards-Based Slide Show System)](http://meyerweb.com/eric/tools/s5/) 🧩
    - *Simple Standards-based Slide Show System* 📜
        - 5 раз «S», или S<sup>5</sup> 5️⃣
    - теперь менее известно, чем [reveal.js](https://revealjs.com/) и другие. 😌
        - но оно было первым, в 2004 🕰️
        - и в [2009 мы уже прикрутили к MediaWiki](https://0x1.tv/312-all-from-mediawiki-add-2010) 🔧
            -  оно плотно легло на MW ✅
                - архитектуру 🧱
                - концепции 💡
                - фичи 🛠️
        - и в целом, за 20 лет никак не устарело и более чем достаточно 🧓
            - для быстрых технических презентаций 🚀
                - от «за 2 минуты до созвона» ⏱️
                - до нестыдного выступления на отраслевой конфе 🎤

![](https://wiki.4intra.net/images/9/96/S5MW.svg)

- Статьи целостны с презентациями 🔗
    - «единый источник правды» 📌
    - презентации можно читать как статьи 📖
    - и наоборот статьи 🔄
        - автоматически показываются как слайды 🖼️
        - специально отмеченные разделы статей 🏷️
            - или все разделы 📚

## Фичи ✨
- Генерация презентации на лету без необходимости дублировать контент ⚙️
    - можно рулить, что показывать, а что оставить в статье 🎚️
- Пользовательские темы / *skins* 🎨
    - можно держать их в MediaWiki 🗂️
-  Автоматическое масштабирование контента 📐
    - включая видео и графику под окно браузера. 🖥️
- Опции 🧰
    - пошаговое отображение списков 👣
    - режим печати (генерация PDF-friendly версии) 🖨️
- Все возможности MediaWiki 🌐
    - совместное редактирование 🤝
    - 100500 расширений для контента 🧩
    - шаблоны-включения и т. п. 📦
- Скрытие служебных разделов вики-статьи из показа презентации 🙈

## Использование

- Добавьте тег `<slideshow>`
    - в атрибутах глобальные настройки презентации
        - `style` — название стиля
        - `scaled` — по умолчанию `true` — автоскейлирование
        - `headingmark` — подстрока, по наличию которой выделяются разделы для показа, как слайды
        - `font` — список желаемых шрифтов
    - также можно задать заголовок и автора и т. п.
        - `;title:`
        - `;author:`
        - …
    - Пример
        ```wiki
        <slideshow style="ispras" scaled="true" headingmark="." font="Calibri, Segoe Print, cursive">
        ;title: Архитектурный план и концепции
        </slideshow>
        ```
- Появится ссылка для запуска показа слайдов

### Подробно
- см. также https://wiki.4intra.net/S5SlideShow/ru

Атрибуты могут задаваться как в XML-подобных атрибутах тега `<slide>`, так и в виде списка определений внутри тега `<slide>`.

#### Атрибуты

| Атрибут | Описание |
|---|---|
| `style` | Имя стиля, используемого для презентации. Встроенные стили — `blue`, `default`, `custis`, `flower`, `yatil`, `pixel`. |
| `headingmark` | Подстрока для отбора заголовков (`== Заголовки MediaWiki ==`), которые станут слайдами. Если заголовок включает эту строку — он станет слайдом. Если не задан — используется значение по умолчанию из конфигурации. Если пуст — ни один подзаголовок не станет слайдом. |
| `incmark` | Подстрока для отбора слайдов, списки внутри которых отображаются «по шагам». |
| `centermark` | Подстрока для отбора слайдов, содержимое которых нужно центрировать. |
| `scaled` | Значения `true`, `yes` или `1` включают индивидуальное масштабирование содержимого слайда. Масштабируются шрифты и изображения (включая SVG). |
| `author` | Автор презентации (для титульного слайда). Может содержать Wiki-код. |
| `title` | Заголовок презентации. |
| `subtitle` | Подзаголовок титульного слайда. |
| ` ` | Строка внизу каждого слайда. Может содержать Wiki-код. Специальное слово `{{date}}` заменяется датой изменения страницы. |

После этого на странице появится изображение-предпросмотр стиля. При клике откроется новое окно браузера с готовой презентацией.
- В Opera режим презентации включается клавишей **F11**.

Все заголовки, помеченные **headingmark**, будут превращены в слайды.

### Печать и PDF-экспорт

S5 поддерживает печать и экспорт в PDF. Интерактив в печати и PDF невозможен — выводится только статическое содержимое.

Списки, показываемые «по шагам», будут отображены целиком.
- Анимации и медиаконтент (например MindMap через расширение MMHandler или видео) не отображаются.

#### Как печатать

- Лучше использовать **Firefox**
    - Chrome может не печатать фоновые изображения и градиенты
        - *так было в 2012, надо проверить в 2026*
- В режиме презентации наведите курсор в правый нижний угол и нажмите иконку принтера.
- Укажите размер бумаги
    - по умолчанию A4 — `297×210` мм.

После перезагрузки страницы:

- Выберите **Файл → Печать**
- Установите тот же размер бумаги и масштаб **100 %**
- В настройках Firefox очистите `header`/`footer`
- При необходимости включите печать фоновых цветов и изображений
- Для PDF выберите PDF-принтер (в Linux он есть, в Windows нужен Ghostscript)
- Нажмите **Печать**

### Стили

Встроенные стили:
- default
    - по умолчанию
    - компактно-информационный стиль
        - без пожирающего пространства мусора, типа хидеров-футеров
            - только полезный прогресс — «сколько слайдов из скольки»
        - клетчатая подложка «драфт-конспектного стиля»
        - максимально читаемые шрифты
- custis
    - пример брендирования
- nobook
- blue
- flower
- yatil
- pixel

Можно создавать собственные стили, используя только wiki-страницы.
- Скин S5 — это CSS-файл со стилями для элементов презентации
    - его можно положить в вики-страницу
        - `MediaWiki:S5/<название стиля>/pretty.css`
            - обычно для правок достаточно этого
            - добавить какое-то брендирование и т. п.
        - но можно лезть и глубже
            - `MediaWiki:S5/<название стиля>/base.css`
            - `MediaWiki:S5/<название стиля>/framing.css`
            - `MediaWiki:S5/<название стиля>/pretty.css`


- Презентацию можно открыть в любом стиле из доступных, не изменяя текст статьи 
    - для этого к параметрам URL нужно добавить значение `&s5skin=имя_стиля`.

#### Панель управления

В правом нижнем углу, если в него переместить курсор, можно увидеть небольшую панель управления презентацией.

#### Инкрементальное отображение

- Нужно редко
    - «театральщина»
    - но можно и может быть полезно

Способы
- В рамках одного «инкрементального» слайда (помеченного **incmark**) все списки — и маркированные, и нумерованные — будут показываться попунктно.
- На любых, не обязательно помеченных **incmark** слайдах можно размещать HTML-элемент с классом «anim» (например `<div class="anim"><div>п.1</div><div>п.2</div></div>` и т. п.), и его содержимое будет показано по шагам.
- Отдельный элемент можно пометить `class="incremental"` и он станет отдельным дополнительным «шагом» показа.

#### Покадровые «анимации»

Если пометить что-нибудь классом «anim over», содержимое элемента будет показываться не просто инкрементально, а по очереди в одном и том же месте. Пример использования: [тестовая презентация](https://wiki.4intra.net/index.php?title=S5SlideShow/anim-over&snapshot=20100802150028 "S5SlideShow/anim-over").

#### Ссылка на слайд

Чтобы дать ссылку на конкретный слайд презентации, можно воспользоваться синтаксисом `#slideN`, где N — номер слайда, начиная с нуля (0 — титульный слайд). Кстати, при обновлении презентации в окне браузера (`F5`, `Ctrl-R`) позиция (номер текущего слайда) сохраняется.

### Совместимость
- ветка `REL1_44` тестировалась на `MediaWiki 1.44` / `PHP 8.4+`.
- подключать
    ```php
    wfLoadExtension( 'S5SlideShow');
    ```
    или, если в нестандартной папке, не `extensions`
    ```php
    wfLoadExtension( 'S5SlideShow', "$myextensions/S5SlideShow/extension.json" );
    ```
